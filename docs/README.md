# WP Seguro — Documentación

Plugin de seguridad para WordPress orientado a rendimiento y claridad. Detecta, clasifica y bloquea tráfico malicioso interceptando peticiones lo más temprano posible.

## Inicio Rápido

1. Instalar y activar el plugin desde el panel de WordPress.
2. Completar el asistente de configuración inicial.
3. Revisar el dashboard de seguridad en **WP Seguro → Dashboard**.
4. Ajustar configuración según las necesidades del sitio.

## Requisitos

- PHP 7.4 o superior
- WordPress 6.0 o superior
- MySQL 5.7 / MariaDB 10.3 o superior
- Extensiones PHP: `mbstring`, `json`, `mysqli`
